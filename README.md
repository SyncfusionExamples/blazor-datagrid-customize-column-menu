# Blazor DataGrid - Customize Column Menu

## Overview

This sample demonstrates how to customize the column menu in the Syncfusion Blazor DataGrid. The implementation focuses on modifying the menu items displayed when users interact with a column menu, allowing developers to tailor the available actions based on application requirements. Customizing the column menu helps simplify the user interface, improve usability, and provide only the operations that are relevant to a particular business scenario. This sample serves as a practical reference for developers who need greater control over DataGrid column interactions and menu presentation.

## Key Features

- Demonstrates customization of column menu items in the Syncfusion Blazor DataGrid.
- Shows how to modify the options displayed in the column menu interface.
- Provides a reference implementation for restricting or customizing column-level menu actions.
- Demonstrates DataGrid user interface customization without altering the underlying data source.
- Allows applications to present only the menu operations required for a specific workflow.
- Illustrates how column menu behavior can be adapted to business requirements.
- Focuses specifically on column menu presentation and interaction customization.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download the repository.
2. Open the solution file `CustomizeColumnMenu.sln`.
3. Restore all NuGet packages.
4. Set the `CustomizeColumnMenu` project as the startup project if required.
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory.

```bash
dotnet restore
dotnet run
```

4. Open the local URL displayed in the terminal after the application starts.
